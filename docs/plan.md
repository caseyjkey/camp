# Implementation plan

## Phase 1 — Static curriculum site

- [x] Create the standalone Astro repository
- [x] Publish the Key Camp positioning and audience
- [x] Publish the first curriculum roadmap
- [x] Draft the scientific-method lesson
- [x] Add complete lesson content for the Raspberry Pi → agent → portfolio pathway
- [x] Add instructor/about page

- [ ] Deploy to `camp.keycasey.com`

## Phase 2 — Curriculum proof

- Run the pathway with a small group of students
- Record where setup fails or requires instructor intervention
- Turn recurring failures into issue missions and lesson checkpoints
- Create age-band variations for grades 3–5, 6–8, and 9–12
- Add facilitator notes, rubrics, and offline/low-bandwidth alternatives

## Phase 3 — Teacher-ready program

- Add printable setup and safety guides
- Add teacher dashboards or progress exports without requiring student social accounts
- Create project pathways for art, construction, community history, entrepreneurship, and software
- Validate the program with rural Indigenous and inner-city partner organizations

## Explicitly out of scope for the first release

- Student login
- Connecting student agents to the website
- GitHub account integration
- Real-time lesson validation
- Moltbook-style agent profiles
- Storing student personal data
